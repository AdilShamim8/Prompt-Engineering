## How to Use This Collection

Start with the main guide for the framework (Role, Task, Format, Details), then jump to the companion file matching your task. Every companion prompt includes purpose, reasoning, an expert variation, and — critically — **limitations and verification guidance**: AI output in business contexts is a draft for human judgment, never a decision.

For the underlying technique (chaining, structured outputs, evaluation), see the [Advanced Prompt Engineering Techniques](../Advanced%20Prompt%20Engineering%20Techniques/) section.

## A Note on the PDF

The PDF in this directory is a snapshot of the main guide from an earlier revision. The Markdown files are the maintained, expanded versions — treat the PDF as a convenient read-only copy, not the source of truth.
