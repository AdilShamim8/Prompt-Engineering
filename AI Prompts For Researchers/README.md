## How to Use This Collection

Start with the main guide for the research-stage overview, then use the companion files for depth on your current task. The unifying discipline across this collection: **AI proposes, databases dispose** — every prompt is designed to keep verification in the hands of the researcher, because fabricated citations and unsupported claims are the documented failure modes of AI in research contexts.

For prompt-technique foundations (few-shot example selection, chaining for review pipelines, structured outputs for extraction tables), see the [Advanced Prompt Engineering Techniques](../Advanced%20Prompt%20Engineering%20Techniques/) section.
