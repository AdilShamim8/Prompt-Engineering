## How to Use This Collection

The main guide gives the breadth; the companion files go deep on each skill. The consistent design rule: **every prompt keeps the cognitive work with you** — AI quizzes, critiques, and structures, but the thinking that your degree certifies stays in your head. Read the Academic Integrity file early: it explains the line that keeps all the other files on the safe side of your course policies.

For the underlying techniques (few-shot practice design, structured study outputs, evaluation of your own learning), see the [Advanced Prompt Engineering Techniques](../Advanced%20Prompt%20Engineering%20Techniques/) section.
