## How to Use This Collection

The main guide covers the teaching workflow broadly; the companion files go deep. Three boundaries run through everything here:

1. **Student data stays protected** — read the Privacy file before using any prompt with student work; anonymization is a discipline, not a find-and-replace
2. **Generated material gets verified** — facts, answers, and examples in AI-drafted teaching materials are checked before they reach students
3. **Judgment stays with the educator** — AI drafts and structures; the professional decisions about students remain with teachers, families, and support teams

For the underlying prompt techniques (few-shot worked examples, structured outputs for rubrics, chaining for lesson design), see the [Advanced Prompt Engineering Techniques](../Advanced%20Prompt%20Engineering%20Techniques/) section.
