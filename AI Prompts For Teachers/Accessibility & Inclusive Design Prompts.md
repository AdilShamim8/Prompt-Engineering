# Accessibility & Inclusive Design Prompts

Companion prompts to the main teachers guide. Designing for accessibility from the start serves every learner, not only those with documented needs — and it is far easier than retrofitting. These prompts help teachers bake access into materials, activities, and assessments, with the classroom teacher's judgment always in the final seat.

***

## 1. Accessible Material Creation

**Prompt:**
```
I am creating [MATERIAL — worksheet / slides / handout] for [GRADE/SUBJECT].
Draft it with these accessibility requirements built in from the start:
1. Plain-language body text (target readability: [GRADE LEVEL]), with key
   vocabulary explicitly defined at first use.
2. Structure: meaningful headings, chunked sections, generous whitespace,
   no walls of text.
3. Multi-modal options: the content expressed in at least 2 formats (text +
   visual organizer, or text + described image).
4. Alt-text suggestions for every visual I plan to include: [LIST VISUALS].
5. A "check your understanding" box at each section — so comprehension gaps
   surface early for every learner, not only in assessment.
```

- **Purpose:** Materials where accessibility is the default, not the accommodation.
- **Why it works:** Starting from plain language and chunked structure is the cheapest universal design — it serves language learners, dyslexic readers, tired readers, and everyone else simultaneously.
- **Use Case:** New units, handout refreshes, slide decks.
- **Expert Variation:**
```
Add the reading-level ladder: the same core content at 3 difficulty levels
(plain / standard / enriched), so every learner meets the same ideas at their
reading comfort — content identical, text complexity differentiated.
```

## 2. Alt-Text and Visual Description Coach

**Prompt:**
```
I am using this image in my [GRADE/SUBJECT] lesson: [DESCRIBE IMAGE or PASTE].
1. Draft alt-text that conveys the image's INSTRUCTIONAL purpose — what a
   learner needs to get from it — not just what it depicts (under ~125
   characters).
2. Draft the long description for complex images (charts, diagrams, maps):
   a screen-reader user should be able to answer the same questions as a
   sighted one.
3. Flag where the image is doing conceptual work that text cannot replace —
   and where a described tactile/drawn alternative would serve better.
4. For the chart specifically: [DESCRIBE CHART] — draft the data table
   equivalent, the truly accessible alternative.
```

- **Purpose:** Visual content that does not silently exclude.
- **Why it works:** The instructional-purpose framing produces alt-text that supports learning rather than the generic "picture of a cell".
- **Use Case:** Slide decks, worksheets, LMS pages, any visual-heavy content.
- **Expert Variation:**
```
Audit my described lesson visuals as a set: which concepts rest ONLY on
visual presentation? Flag them — those are the lessons where absence
(instructor illness, remote pivot) becomes inaccessibility.
```

## 3. Multiple Means of Engagement & Expression

**Prompt:**
```
My lesson objective: [OBJECTIVE]. Traditional format: [DESCRIBE — e.g.,
written quiz]. Help me design alternatives across the engagement and
expression dimensions:
1. Three ways learners can DEMONSTRATE this objective (write it, present it,
   build/diagram it, teach it back, record it) — with the same rubric applied
   to all.
2. Two ways to vary the INPUT: how else the core content can be encountered
   beyond reading/listening.
3. For each alternative: what it preserves of the objective, and what
   assessment consideration it creates (time, rubric wording, logistics).
4. The choice architecture: how I present options without creating a
   "lesser" track — framing and equivalence matter.
```

- **Purpose:** Assessment and learning that measure the objective, not one narrow skill channel.
- **Why it works:** The equivalence framing ("same rubric, same objective") prevents differentiation from becoming stratification — the most common UDL implementation failure.
- **Use Case:** Unit design, assessment makeovers, project-based learning.
- **Expert Variation:**
```
Add the workload reality check: which of these alternatives can I actually
sustain with [N] students? Design the sustainable subset rather than the
aspirational full set.
```

## 4. Inclusive Language & Representation Review

**Prompt:**
```
Review my material for inclusive design: [PASTE MATERIAL or describe examples,
names, contexts used].
1. Names and examples: do they represent a plausible range of cultures without
   tokenizing? Suggest natural substitutions where the set is homogeneous.
2. Assumption check: family structures (two-parent? shared meals?), economic
   assumptions (vacations, allowances, home tech), geographic defaults
   (driving, suburbs), and body/ability assumptions in scenarios.
3. Cultural load: idioms and cultural references that add comprehension cost
   for multilingual learners — list them with plain alternatives.
4. Stereotype audit: who is active/passive, expert/novice, problem/hero in
   my examples and word problems?
```

- **Purpose:** Materials where every learner finds themselves as the hero sometimes and never only as the example.
- **Why it works:** The assumption checklist covers the four most common hidden exclusions in classroom materials — family, economics, geography, ability.
- **Use Case:** New material creation, annual review of reused materials.
- **Expert Variation:**
```
Adapt for my actual class profile: [DESCRIBE STUDENT COMMUNITY — known
languages, cultures, contexts]. Localize the examples so my specific learners
see their world in the material.
```

## 5. Accommodation Implementation Planner

**Prompt:**
```
I have a learner with accommodations for: [ACCOMMODATION TYPE — e.g., extended
time, screen reader, frequent breaks, alternate format]. My upcoming lesson:
[DESCRIBE].
1. What these accommodations mean for each component of my lesson —
   concretely: what I prepare differently, what happens in the moment, what
   I prepare for substitutes.
2. The dignity check: how each accommodation is implemented without singling
   the learner out — what is built into the whole-class design versus what
   is individual.
3. The barrier inventory: where does my current lesson design undermine the
   accommodation despite good intentions (timed activities with no flex,
   materials not convertible, group configurations that force disclosure)?
4. What I should confirm with my school's support team: [flag questions —
   not answers; they hold the specifics].
```

- **Purpose:** Accommodations that work in real classrooms, with the learner's dignity intact.
- **Why it works:** The "built into whole-class design vs. individual" distinction is the practical core of dignified accommodation.
- **Use Case:** IEP/504 implementation (US context varies by country), ELL support, injury/illness adjustments.

**Limitations & verification:** Accommodation specifics live in official plans and support professionals — this prompt organizes implementation; it never overrides or interprets the official plan. Where the prompt's suggestions conflict with the plan, the plan wins, and the support team clarifies.

## 6. Physical & Sensory Environment Audit

**Prompt:**
```
Audit my classroom setup for sensory and physical access: [DESCRIBE ROOM —
seating, sightlines, acoustics, movement paths, display areas, lighting].
1. Sightlines: where can every learner see the board/screen AND my face
   (for speechreading)? Where do current obstructions break this?
2. Sound: for a learner with hearing devices or attention differences, what
   in the room fights the signal (hum, echoes, competing noise)?
3. Movement: wheelchair/walker paths, and deliberate movement options for
   learners who focus better standing or pacing.
4. Overstimulation: what is on my walls and how much of it is instructional
   versus noise? Design the declutter with a "quiet zone" option.
5. Seating alternatives: what low-cost options (standing table, floor seating,
   fidget-friendly seating) could I trial without stigmatizing anyone?
```

- **Purpose:** The physical environment as part of the lesson design.
- **Why it works:** Treats the room as an adjustable teaching tool with specific, checkable dimensions rather than a fixed given.
- **Use Case:** Classroom setup, mid-year environment resets, shared-space teaching.

***

## Shared Verification Rules for All Accessibility Prompts

1. **Accessibility standards are external.** For institutional materials, verify against your school's accessibility requirements (and, where applicable, WCAG and national standards) — AI output is a strong draft, not compliance certification.
2. **The learner and family know their needs best.** Use these prompts to prepare, never to substitute for the official accommodation plan or the support team's expertise.
3. **Universal design beats retrofit.** Where a design choice serves everyone, prefer it to an individual add-on — both for dignity and for sustainability.
4. **Test with the tools your learners use.** Screen readers, captions on, printed grayscale: actually run the material through the channels it will be consumed on.
