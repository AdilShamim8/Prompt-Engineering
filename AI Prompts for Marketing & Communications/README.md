## How to Use This Collection

Start with the main guide for the CLEAR framework and campaign templates; use the companion files for the channel and discipline depth. Two disciplines run through everything:

1. **Every claim gets verified before it ships** — the Ethical Marketing file is not optional reading; AI-generated statistics, testimonials, and comparisons are compliance exposure until substantiated
2. **The numbers get recomputed** — analytics outputs from AI are drafts until checked against source data

For the underlying prompt techniques (structured outputs for reporting, chaining for campaign pipelines, evaluation of marketing prompts), see the [Advanced Prompt Engineering Techniques](../Advanced%20Prompt%20Engineering%20Techniques/) section.
